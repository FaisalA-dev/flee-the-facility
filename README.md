# Flee The Facility

Flee the Facility is text based python game where the player wakes up inside of a facility and needs to escape. 

# Features 
- 3 different endings 
- 3 different story routes 
- inventory system
- save system 
- audit logging 
- SHA-256 hashing
- NPC interactions 
- Input validation

## Three different routes 
- Impersonation Route 
- Blackout Route
- Hacking Route
